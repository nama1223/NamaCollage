## Overview

This app was developed as an alternative to the Android image merging app "Joint Pics."
I tried over 10 different collage apps, but none of them could replicate the following features of Joint Pics:

* Automatically adjusts the size of images to match other images
* Fully preserves the original shape of images instead of cropping them to fit a frame

However, I added various features, thinking it would be convenient to be able to perform tasks that I used to do with other apps in conjunction with Joint Pics.
As a result, the merging feature has become just one part of the app as a whole.
Now, I often just load and process a single image. I'm a heavy user myself.

### Merging
Combines multiple images into one.
What you can do in the [Image] tab:
* Select images to merge
* Change image placement
* Basic image editing (trimming, middle cut-out, rotation, flipping, color adjustment)

The middle cut-out removes a strip from the middle of an image, vertically or horizontally, instead of trimming the edges.
For example, you can cut out just the advertisements from a website screenshot.

[Preview] Tab Features
- Check the combined image result
- Unify width, height, and longest side
- Set spacing between images, surrounding margins, background color of spacing and margins, and border settings

### Topping
This function allows you to "place" various elements on the combined image.
- Text, images, lines and arrows, shapes, and concentration lines
- Filters (blur, mosaic)
- Freehand drawing is also possible for lines and filters.
- Undo/Redo function is also included.

### Save
- Export in JPEG/PNG/WebP, specifying image quality or file size.
- Save in a proprietary format (.namaco) with editing data for later re-editing.
- You can also save just the toppings separately (.namatop) for reuse.

### Screen Explanation (How to read screenshots)
1) "Image" tab: Add and rearrange materials, and access the editing menu by long-pressing.
2) "Preview" tab: Specify the unification method and margins, and check the combined image result.
3) "Toppings" tab: Add and adjust text, shapes, and filters.

4) "Save" tab: Specify format and quality, and save data for re-editing.
