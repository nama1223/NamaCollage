## 概要

このアプリは、android向け画像結合アプリ「Joint Pics」の代替を目指して開発されました。
コラージュ系のアプリを10種類以上試しましたが、Joint Picsの持つ以下の機能を再現できるものがなかったのです。

・自動で他の画像とサイズを合わせてくれる
・枠に合わせて画像をカットするのではなく、元の形をフルに生かす

ただ、Joint Picsと併用して他のアプリでやっていた作業もついでに出来たら便利だな、と色々と追加していった結果、
結合機能が全体の一部みたいになってしまいました。
今となっては画像一枚だけ読み込んで加工する事もよくあります。作者自身がヘビーユーザー。

### 結合
複数の画像をくっつけて一枚にします。
【画像】タブで出来ること
・結合する画像の選択
・画像配置の変更
・それぞれの画像の基本加工（トリミング・中抜き・回転・反転・カラー調整）

中抜きとは画像の端ではなく途中の部分を縦か横に切り落とす機能です。
たとえば、Webサイトのスクリーンショットから広告だけ切り落としたりできます。

【プレビュー】タブで出来ること
・結合結果の確認
・横幅・高さ・長辺の統一
・画像同士の間隔・周囲の余白・間隔や余白の背景色・枠線などの設定

### トッピング
結合後の画像に色々なものを「乗せる」機能です。
・テキスト・画像・線や矢印・図形・集中線
・フィルタ(ぼかし・モザイク)
線やフィルタはフリー描画も可能。
「元に戻す／やり直し」機能もついています。

### 保存
JPEG／PNG／WebP、画質か容量を指定して書き出し。
編集データ入りの独自形式（.namaco）で保存すれば、あとから再編集もできます。
トッピング部分だけ使い回せるように(.namatop)で保存する機能も追加しました。

### 画面説明（スクリーンショットの見方）
1) 「画像」タブ: 素材の追加・並べ替えと、長押しで開く加工メニュー。
2) 「プレビュー」タブ: 統一方法と余白まわりを指定して、結合結果を確認。
3) 「トッピング」タブ: 文字・図形・フィルタの追加と調整。
4) 「保存」タブ: 形式・品質の指定と、再編集用データの保存。

## 使い方
